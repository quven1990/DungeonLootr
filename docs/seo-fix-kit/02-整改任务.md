## DL-05｜P1｜修正掉落计算器说明（数学问题已确认）
/tools/drop-chance-calculator：
独立且每次固定概率p，前n次至少一次=1-(1-p)^n；
首次成功期望尝试次数=1/p；
达到目标概率q的最少尝试次数=ceil(log(1-q)/log(1-p))。
2%时：期望50次，前50次至少一次约63.6%；达到50%需35次、90%需114次、95%需149次、99%需228次。
替换“A 2% drop is not expected every 50 runs”为准确英文：
“At a constant 2% chance per independent attempt, the expected wait for the first drop is 50 attempts. That is not a guarantee: the chance of at least one drop within 50 attempts is about 63.6%.”
明确一次attempt是什么；一局有多个掉落机会不能直接等同一局一次。
p=0：正目标不可能/无穷；p=1：正目标一次；q=0：0次；q=1且0<p<1：无有限保证；n=0：0%。
输入百分数转小数；拒绝负数、超范围、非数字、负数/小数次数；说明无保底/固定概率假设。
默认2%只是示例输入，不能暗示游戏真实掉率。幸运加成/保底未经确认不建模。
内链“expected runs”与90%/95%目标次数区分用词。
